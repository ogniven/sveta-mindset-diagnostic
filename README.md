# SVETA MINDSET Diagnostic

Статический сайт: HTML, CSS и vanilla JavaScript. Сборка, зависимости и backend не нужны.

## Локальный просмотр

Из корня проекта: `python -m http.server 8000 --bind 127.0.0.1`.
Откройте http://127.0.0.1:8000/.

## Публикация

Для GitHub Pages выберите ветку с готовыми файлами и папку `/ (root)`.
Относительные пути работают и под `/sveta-mindset-diagnostic/`.

## Диагностика

Девять шагов, F0/F1, фиксированные правила SITE_SPEC v1.1 и последовательные результаты:
weak, moderate, strong, mixed pair, mixed complex. В complex список центров намеренно
опущен: автоматического выбора победителя нет.

Ответы и необязательная обратная связь хранятся только в памяти страницы.
Перезагрузка и повторное прохождение сбрасывают ответы. Изменение раннего ответа
сбрасывает последующие зависимые ответы; обычный переход назад их сохраняет.
Свободный текст не интерпретируется алгоритмом и безопасно выводится отдельными цитатами.

Оба CTA ведут на https://t.me/sveta_mindset без передачи ответов.
Формы, аналитики и внешних API нет.

Утверждённые тексты и правила: `docs/SITE_SPEC.md`. Инструкции проекта: `AGENTS.md`.
